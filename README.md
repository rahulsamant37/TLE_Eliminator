# 🚀 TLE Eliminators - Competitive Programming Solutions

Welcome to my repository of solutions for the [TLE Eliminators Courses](https://www.tle-eliminators.com/courses). This repository documents my progress, assignments, and problem-solving journey through various cohorts and levels of the program.

## 📖 About TLE Eliminators
[TLE Eliminators](https://www.tle-eliminators.com/) provides structured competitive programming courses, guiding students from fundamental programming concepts to advanced data structures and algorithms. The platform features curated problem sheets, primarily from Codeforces, CSES, and AtCoder, aimed at building strong algorithmic thinking.

## 🗂️ Repository Structure

This repository is organized by cohorts (e.g., `tle-07`, `tle-10`) and difficulty levels. Each level is further divided into weekly progress and specialized algorithmic topics.

### 🎯 TLE Cohort 07 (`/tle-07`)

#### Level 1: Fundamentals & Basic Data Structures
* **Week 1:** Basic Syntax, Arithmetic Operators, and Logic Building
* **Week 2:** Loops (For/While), Arrays, Strings, and Data Types
* **Week 3:** Time Complexity, Math Fundamentals, and Ad-hoc Problems
* **Week 4:** Hashing, Counting Divisors, and Implementation Basics

#### Level 2: Algorithms & STL
* **Week 1:** C++ STL (Vectors, Sets, Heaps), Binary Search Fundamentals

### 🎯 TLE Cohort 10 (`/tle-10`)

#### Level 2: Advanced Topics
* **Prefix Sum:** Prefix sum arrays, range sum queries, and optimizations (`/prefix-sum`)

## 💻 Tech Stack
* **Language:** C++ (`std::c++17` or higher recommended)
* **Testing Platforms:** Codeforces, CSES Problem Set

## 📝 Commit Convention
This repository follows standard [Conventional Commits](https://www.conventionalcommits.org/) for clear version control history:
* `feat:` - Adding new task solutions (`.cpp` files)
* `chore:` - Adding/updating input and output text files (`.txt`), executables
* `refactor:` - Restructuring code, renaming, or moving directories
* `fix:` - Fixing bugs in existing solutions

## 🚀 How to Run
To compile and run any C++ solution locally:

```bash
# Navigate to the specific directory
cd tle-07/level-01/week-01/tasks/

# Compile the C++ file
g++ -std=c++17 001.cpp -o solution

# Run the executable
./solution
```
